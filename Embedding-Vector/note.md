### Embedding = a vector that carries semantic meaning

- An embedding is a representation — it's the process or result of mapping something (a word, sentence, image, etc.) into a meaningful, lower-dimensional space where similar items end up close together.
- An embedding is learned (by a neural network), not hand-crafted.
- It's a concept/method, not just a list of numbers.


## Libraries:
### SentenceTransformers (SBERT)
- https://www.sbert.net
- SentenceTransformers is a Python module for using and training state-of-the-art embedding and reranker models. It supports working with text, images, audio, and video.
